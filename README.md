# ParentFit

**Seamless Exercise Routine Logger & Resource Hub for Busy Parents.**

ParentFit is a premium web application designed to help parents effortlessly track their fitness journeys, manage workout resources, and maintain consistency amidst a busy lifestyle. Built with a focus on speed, aesthetics, and privacy.

---

## ✨ Key Features

- **📊 Dashboard**: Quick overview of your activity, streaks, and progress.
- **🏋️ Exercise Logger**: Optimized flow for logging routines with smart defaults and easy tag selection.
- **📚 Knowledge Hub**: A curated library of fitness and nutrition resources tailored for parents.
- **☁️ Cloud Synchronization**: Seamless, secure data persistence across devices using private remote storage.
- **📱 Mobile-First Design**: A glassmorphic, touch-friendly interface optimized for parents on the move.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ttaruntej/parentfit.git
   cd parentfit
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 🛠️ Technology Stack

- **Frontend**: React + Vite
- **Styling**: Vanilla CSS (Custom Design System)
- **Icons**: Lucide React
- **Persistence**: Dynamic JSON Synchronization via REST API

## 🔒 Privacy & Data

Your data is stored securely in your private cloud storage. Access is managed through a personal token configured in the application's **System Settings** menu.
